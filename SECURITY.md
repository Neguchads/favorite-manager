# Política de segurança

O Favorite Manager manipula favoritos do navegador e permissões opcionais de acesso a sites. Vulnerabilidades envolvendo permissões, sincronização, criptografia, injeção de conteúdo ou exposição de dados devem ser tratadas de forma privada.

Não publique chaves de sincronização, dumps reais de favoritos, tokens, credenciais ou uma prova de conceito explorável em issue pública. Prefira **Security > Report a vulnerability** quando disponível.

Se um segredo real for publicado, revogue ou rotacione primeiro e só depois remova-o do repositório e do histórico.
